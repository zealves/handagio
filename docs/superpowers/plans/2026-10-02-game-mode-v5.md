# Modo de jogo v5 — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O jogo fica só com níveis e em silêncio fora da música. A pontuação passa a castigar os toques errados. A nota, o alvo e o dedo usam a mesma cor, e só os dedos que jogam ficam em destaque. Fecha também os três pontos da revisão anterior.

**Architecture:**
- **Lógica pura** (`src/game/`): `wrongTaps`, a precisão nova, a tolerância do vizinho (`Chart.split`) e `isMusicTime`.
- **Sessão:** o silêncio fora da música, a saída do Treino e a limpeza das preferências.
- **UI:** o menu só com níveis, o resultado, o alvo em pílula no `drawGame` e o destaque no `drawOverlay`.

**Tech Stack:** TypeScript estrito, React 18, Zustand, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-02-game-mode-v5-design.md`

## Global Constraints
- `src/game` sem React nem áudio. Valores a 60 fps fora do estado React.
- Textos em `pt.ts` e `en.ts`. `check-bundle-texts`. Alvos ≥ 44 px (com a exceção dos dedos a 320 px). Comentários e testes em pt-PT. Constantes com nome.
- Antes de cada commit: `npm run build && npm run lint && npm test`. Commits em inglês, Conventional Commits, sem atribuição. Ramo `feat/game-mode`.
- **Valores:**
  - `NEIGHBOUR_GRACE_S` 0,15
  - peso dos errados na precisão: 0,5
  - alvo: 1,2× a largura da nota (sem passar a faixa) e 1,4× a altura
  - destaque nas mãos: ~1,3× o anel de hoje
  - outros dedos: `#8a93a6`, com opacidade ~0,25
  - esqueleto com ~40% da opacidade
  - Cedo/Tarde a branco

## Review Focus
1. **Silêncio:** nenhuma dobra soa com `game !== null` fora de `isMusicTime`. Inclui o menu, a contagem inicial, a contagem depois de uma pausa, a cauda final e o resultado, e também o modo contínuo e o teclado.
2. **Tirar o Treino** não pode partir os níveis, o "Repor as preferências" nem as preferências antigas guardadas (chaves que já não existem).
3. **A tolerância do vizinho** não pode ignorar toques errados de outra mão nem de faixas a 2 de distância.
4. **A precisão nova** fica limitada a [0, 1], e as estrelas e o desbloqueio usam-na.

### Task 1: Lógica — toques errados, vizinhos e tempo da música

**Files:**
- `src/game/score.ts`, `run.ts`, `types.ts`, `generator.ts`, `config.ts`
- os testes deles

- [ ] **`config.ts`:** `/** Um toque errado até aqui depois de um acerto numa faixa vizinha da mesma mão não conta (o dedo ao lado arrastado). */ export const NEIGHBOUR_GRACE_S = 0.15;` e `/** Peso de um toque errado na precisão. */ export const WRONG_TAP_WEIGHT = 0.5;`.
- [ ] **`types.ts`:**
  - `Chart` ganha `split: number`, e o gerador preenche-o com o `split` que usou;
  - `GameResult` ganha `wrongTaps: number`;
  - os testes que constroem `Chart` à mão acrescentam `split`.
- [ ] **`score.ts`:**
  - `wrongTaps = 0`;
  - `wrongTap(): void { this.wrongTaps++; this.combo = 0; }`;
  - `nearTap(): void { this.combo = 0; }`;
  - `result(total)` com `accuracy = total + WRONG_TAP_WEIGHT * wrongTaps > 0 ? Math.min(1, (perfect + 0.5 * good) / (total + WRONG_TAP_WEIGHT * wrongTaps)) : 0` e `wrongTaps`.
  - **Testes:**
    - 2 perfeitos, 0 bons, 2 notas e 2 errados dão 2 / (2 + 1) ≈ 0,667;
    - `wrongTap` e `nearTap` põem o combo a 0;
    - `wrongTaps` aparece no resultado.
- [ ] **`run.ts`:**
  - `press(lane, now, fromCamera)`:
    - quando `judge.press` dá `null` e `this.isMusicTime(now)`:
      - se `lastHit` (a faixa e o instante do último acerto) é vizinho (`|lane − lastHit.lane| === 1` e `lane < split === lastHit.lane < split`) com `now − lastHit.at ≤ NEIGHBOUR_GRACE_S`, devolve `null` sem castigo;
      - senão chama `score.wrongTap()`, `last = { kind: 'wrong', at: now }` e devolve `{ kind: 'wrong', lane }`;
    - Cedo/Tarde chamam `score.nearTap()`;
    - os acertos guardam `lastHit`.
  - `PressResult` ganha `{ kind: 'wrong'; lane }`, e `last.kind` ganha `'wrong'` (o canvas pode ignorá-lo ou mostrar "Errado" em vermelho; a Task 3 decide e faz o i18n).
  - **Novo:**

    ```ts
    /** Durante a música: do fim da contagem à última nota + NEAR_S (antes, depois e em pausa, nada soa nem conta). */
    isMusicTime(now: number): boolean {
      if (this.state === 'paused' || this.state === 'over') return false;
      const lastNote = this.times.length ? this.times[this.times.length - 1] : this.start;
      return now >= this.countTo && now <= lastNote + NEAR_S;
    }
    ```

  - **Testes:**
    - `isMusicTime` antes do `countTo` (falso), durante (verdadeiro), depois da última nota + 0,35 (falso), em pausa (falso) e depois de uma retoma, durante a nova contagem (falso);
    - um toque errado durante a música conta, e fora da música não conta;
    - a tolerância: vizinho da mesma mão até 0,15 s, ignorado; com 0,2 s, conta; da outra mão, conta; a 2 faixas de distância, conta;
    - Cedo/Tarde partem o combo.
